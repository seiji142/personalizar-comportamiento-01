Este es un caso común en manipulación de datos. ### 2. Propuesta de solución ```python numeros = [5, 2, 8, 1, 9, 3] # Opción 1: Usar sorted() (crea nueva lista) ordenados = sorted(numeros) print(ordenados) # [1, 2, 3, 5, 8, 9] # Opción 2: Usar .sort() (modifica la lista original) numeros.sort() print(numeros) # [1, 2, 3, 5, 8, 9] # Opción 3: Orden descendente ordenados_desc = sorted(numeros, reverse=True) print(ordenados_desc) # [9, 8, 5, 3, 2, 1] ``` ### 3. Razonamiento - **`sorted()`**: Crea una nueva lista sin modificar la original. Ideal cuando necesitas conservar ambos estados. - **`.sort()`**: Modifica la lista in-place, es más eficiente en memoria. - Ambos usan el algoritmo Timsort (O(n log n)), que es el estándar en Python. ### 4. Sugerir mejoras - **Para listas muy grandes**: Usar `numpy.sort()` para mejor rendimiento. - **Orden personalizado**: Usar `key` parameter, ej: `sorted(numeros, key=abs)` para ordenar por valor absoluto. - **Ordenar por propiedad de objetos**: `sorted(lista, key=lambda x: x.edad)`.
