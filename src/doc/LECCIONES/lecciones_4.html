Lecciones Aprendidas

1. MCP Bridge funciona correctamente

El bridge traduce MCP → HTTP y permite que los modelos usen brain-ai-01. Verificado con llamada exitosa a brain-ai_memory_search.

2. Los prompts explícitos funcionan

Cuando el prompt dice "usa la herramienta brain-ai_memory_search", el modelo la usa. D2 pasó de FAIL a PASS con prompt explícito.

3. Los modelos no usan tools sin instrucción explícita

Si el prompt solo dice "busca en memoria", el modelo puede no usar la tool. Necesita decir "usa brain-ai_memory_search".

4. La solución es reutilizable

El bridge vive en brain-ai-01 (una sola copia). Cada proyecto solo necesita copiar la config MCP y crear .ai/MEMORY.md.
