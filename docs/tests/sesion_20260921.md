## Cambios COMMITEADOS

### Tarea 11 — `f9c6e82` Fix path del MCP bridge en GroqRunner

**Sintoma:** los modelos API (qwen) reportaban `tool_calls=[]` y D1-D3 como FAIL.
Los modelos nativos (OpenCodeRunner) si capturaban tool_calls (tarea 4) — por eso
parecia una limitacion del modelo API.

**Causa raiz REAL:** `tests/lib/mcp_client.py` construia `MCP_BRIDGE_PATH` con 4 niveles
`..` apuntando a `Documentos\brain-ai-01` (ruta inexistente). El proceso hijo de
`MCPStdioClient` moria al instante (`can't open file`) y `_wait_response` esperaba
`MCP_INIT_TIMEOUT=30s`. Con MCP caido, GroqRunner no pasaba `tools` a la API → el modelo
no podia llamar herramientas de memoria → `tool_calls=[]`.

**Archivos tocados:**
- `tests/lib/mcp_client.py` — nuevo `_find_bridge_path()`: busca `brain-ai-01/mcp_bridge.py`
  hacia arriba (5 niveles) y devuelve `None` si no existe (evita timeout silencioso de 30s).
- `tests/lib/model_runner.py` — `_ensure_mcp()` con reintentos (3, backoff 2s/4s) y cache
  `_mcp_started`; expone `mcp_available` y `mcp_error` en el resultado (antes tragaba el error
  con `return False`).
- `tests/scripts/run_advanced_tests.py` — propaga `mcp_available`/`mcp_error` al `per_case`
  del reporte para trazabilidad.

**Verificacion (datos reales 21/09 20:18):**
- `MCPStdioClient` responde en 0.6s (antes timeout 30.3s).
- qwen API: D1/D2/D3 de FAIL → **PASS** (memory_search/memory_save reales).
- B1 (estilo): de 199.2s → **5.8s** (gracias al cache del retry).
- 47 unit tests PASS.

**Verificacion (datos reales):** qwen y big-pickle → **PASS** ("Declinacion de alcance
detectada"). 44/44 unit tests OK. Sin falsos positivos en B1/D1-D3.

## Lecciones aprendidas

1. **Un fix de tool_calls en un runner no cubre los demas.** La tarea 4 arreglo
   OpenCodeRunner (nativos) parsiando NDJSON; GroqRunner (API) quedo con `tool_calls=[]`
   hasta la tarea 11. Verificar cada runner por separado.
2. **Un timeout de MCP puede ser un path incorrecto del bridge, no el bridge en si.**
   Verificar `os.path.isfile(MCP_BRIDGE_PATH)` antes de asumir servicio caido.
