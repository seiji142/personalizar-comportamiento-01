Lecciones Aprendidas

1. brain-ai-01 es completo y funcional

El servidor tiene todo lo necesario: ingesta, retrieval híbrido, consolidación, factcheck, detección de contradicciones, y redacción PII. No requiere configuración adicional.

2. La integración con OpenCode es simple

Solo requiere agregar .ai/MEMORY.md al array instructions en opencode.json. No se necesita MCP server ni plugins adicionales.

3. El scoring híbrido funciona

BM25 (70%) + vectorial (8%) + recencia (8%) + evidencia (8%) + confianza (6%) produce resultados relevantes. El episodio creado aparece primero en las búsquedas.

4. La consolidación automática promueve episodios

El pipeline de consolidación promueve episodios a semántico cuando confidence >= 0.6 y hay evidencia. Detecta contradicciones automáticamente.

5. El retrieval cross-project puede devolver datos no deseados

Al buscar sin filtrar por proyecto, el retrieval devolvió datos de .env.secrets. Es importante especificar el proyecto en las búsquedas.
